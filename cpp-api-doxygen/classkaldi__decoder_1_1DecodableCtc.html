Detailed Description

Decodable over a matrix of CTC log-probabilities.

Row t holds the per-class log-probs of frame t; the matrix is copied at construction. Labels are one-based: class c is column c-1.

kaldi_decoder::FloatMatrix log_probs(2, 2);
log_probs << -0.1f, -5.0f, -5.0f, -0.1f;
kaldi_decoder::DecodableCtc dec(log_probs);
float s = dec.LogLikelihood(0, 1); // -0.1
