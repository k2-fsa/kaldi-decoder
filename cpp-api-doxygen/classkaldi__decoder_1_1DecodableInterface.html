Detailed Description

Decodables implement this interface to feed scores to decoders.

Keep the interface small and model-agnostic (kaldi's design): do not assume scores come from a vector of floats, and do not assume the decoder queries frames strictly left-to-right.

Lifetime:
Decoders store a pointer/reference to the decodable without owning it. The caller must keep the object alive for the whole decode.
See also
LatticeFasterDecoderTpl for the main consumer.

Whether this is the last frame with scores.

Frames are zero-based; IsLastFrame(-1) is false unless the input is empty. In online settings prefer NumFramesReady(): this method may return false while input is pending and true once termination is decided.

Parameters
[in]frameFrame index, 0-based.
Returns
True if frame is the last frame of the utterance.

Acoustic log-likelihood of one label at one frame.

The value is negated inside the decoder (costs are -log-likelihoods), so higher is better. Frames are zero-based; labels (index) are one-based. Verify NumFramesReady() > frame before calling.

Parameters

The log-likelihood \(\log p(i \mid t)\).

virtual int32_t kaldi_decoder::DecodableInterface::NumFramesReady ( ) const
inlinevirtual

Number of frames currently available.

May grow over time in streaming setups; the decoder will not query beyond it. This (rather than IsLastFrame) is the primary way decoders know how far they can proceed.

Returns
The number of frames with scores available.
