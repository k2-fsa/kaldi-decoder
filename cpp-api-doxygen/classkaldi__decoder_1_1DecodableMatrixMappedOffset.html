Detailed Description

Incrementally-fed matrix decodable for streaming decoding.

Log-likes live in a matrix that grows via AcceptLoglikes(); the frame-index of the first row is the current offset. Intended for multi-threaded decoding (mutexes are the caller's job). Querying a frame below FirstAvailableFrame() is an error – those rows are gone.

DecodableMatrixMappedOffset dec(tm);
dec.AcceptLoglikes(&chunk1, 0);
dec.AcceptLoglikes(&chunk2, 1); // drop 1 oldest frame
dec.InputIsFinished();

int32_t frames_to_discard )

Logically, this function appends 'loglikes' (interpreted as newly available frames) to the log-likelihoods stored in the class.

This function is destructive of the input "loglikes" because it may under some circumstances do a shallow copy using Swap(). This function appends loglikes to any existing likelihoods you've previously supplied.

Whether this is the last frame with scores.

Frames are zero-based; IsLastFrame(-1) is false unless the input is empty. In online settings prefer NumFramesReady(): this method may return false while input is pending and true once termination is decided.

Acoustic log-likelihood of one label at one frame.

The value is negated inside the decoder (costs are -log-likelihoods), so higher is better. Frames are zero-based; labels (index) are one-based. Verify NumFramesReady() > frame before calling.
