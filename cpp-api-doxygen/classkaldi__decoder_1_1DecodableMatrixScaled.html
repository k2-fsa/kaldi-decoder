Detailed Description

Plain matrix-backed decodable with an acoustic scale (no tid map).

Indices are the matrix columns directly (one-based): the score of index i at frame t is scale * likes(t, i - 1). Use this when the caller already has per-index (not per-pdf) scores, e.g. for CTC-like graphs.

Whether this is the last frame with scores.

Frames are zero-based; IsLastFrame(-1) is false unless the input is empty. In online settings prefer NumFramesReady(): this method may return false while input is pending and true once termination is decided.

Acoustic log-likelihood of one label at one frame.

The value is negated inside the decoder (costs are -log-likelihoods), so higher is better. Frames are zero-based; labels (index) are one-based. Verify NumFramesReady() > frame before calling.
