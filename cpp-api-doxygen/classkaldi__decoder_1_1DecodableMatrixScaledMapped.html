Detailed Description

Matrix-backed decodable with acoustic scale and tid->pdf mapping.

This is kaldi's DecodableMatrixScaledMapped (src/decoder/decodable-matrix.h). The matrix must have tm.NumPdfs() columns; row t holds the per-pdf log-likelihoods of frame t. Lookups use one-based transition-ids: [ \mathrm{LogLikelihood}(t, \mathit{tid}) = s \cdot L_{t,\,\pi(\mathit{tid})} ] with $s $ the scale and $\pi $ the tid->pdf map.

kaldi_decoder::DecodableMatrixScaledMapped dec(tm, likes, 0.083f);
float s = dec.LogLikelihood(0, 1);
