Detailed Description

Beam-pruned Viterbi decoder (kaldi's FasterDecoder).

This is kaldi's src/decoder/faster-decoder.h: the fastest decoder; for FSTs without self-loops and without lattice output. For general HMM graphs use LatticeFasterDecoderTpl.

kaldi_decoder::FasterDecoderOptions opts; // beam=16, ...
kaldi_decoder::FasterDecoder decoder(graph, opts);
decoder.InitDecoding();
decoder.AdvanceDecoding(&decodable);
fst::Lattice best;
decoder.GetBestPath(&best);

◆ GetBestPath()

bool kaldi_decoder::FasterDecoder::GetBestPath ( fst::MutableFst< fst::LatticeArc > * fst_out,
bool use_final_probs = true )

Get the decoding traceback.

If use_final_probs is true AND we reached a final state, it limits itself to final states; otherwise it gets the most likely token without final-probs. Returns true if the output best path was not the empty FST (false only in unusual circumstances where no tokens survived).

Parameters
[out]fst_outThe best path (a linear Lattice FST).
[in]use_final_probsAccount for final-probs (default true).
