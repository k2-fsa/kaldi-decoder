Detailed Description

Simplest possible decoder, included largely for didactic purposes and as a means to debug more highly optimized decoders.

See kaldi's doc/decoders.dox for more information.

Used by:
Small-graph decoding, tests, and as a reference for the faster decoders.
See also
FasterDecoder, LatticeSimpleDecoder, DecodableInterface

float kaldi_decoder::SimpleDecoder::FinalRelativeCost ( ) const

*** The next functions are from the "new interface". ***

How far the best final cost is from the best cost overall.

Serves the same function as ReachedFinal() with more information: the difference between the best (final-cost plus cost) of any token on the final frame and the best cost of any token on the final frame. Infinity means no final states were present on the final frame; usually nonnegative.

Returns
The relative final cost (see above).

◆ GetBestPath()

bool kaldi_decoder::SimpleDecoder::GetBestPath ( fst::Lattice * fst_out,
bool use_final_probs = true ) const

Get the decoding traceback.

If use_final_probs is true AND we reached a final state, it limits itself to final states; otherwise it gets the most likely token without final-probs. fst_out will be empty (Start() == kNoStateId) if nothing was available due to search error. If Decode() returned true, it is safe to assume GetBestPath() returns true.

Parameters
[out]fst_outThe best path (a linear Lattice FST).
[in]use_final_probsAccount for final-probs (default true).
Returns
True if the output lattice was nonempty.
