Detailed Description

Matrix-backed decodable for CTC-style per-frame log-probs.

An original class (kaldi has no CTC decodable); in spirit it is src/decoder/decodable-matrix.h's DecodableMatrixScaled without any transition-model mapping. Hand in a (num_frames, num_classes) matrix of log-probabilities; the class copies it.

Indices are one-based (openfst convention): LogLikelihood(t, 1) reads column 0.

kaldi_decoder::FloatMatrix log_probs(2, 2);
log_probs << -0.1f, -5.0f, -5.0f, -0.1f;
kaldi_decoder::DecodableCtc dec(log_probs);
float s = dec.LogLikelihood(0, 1); // -0.1

  • Returned lattices/sequences are owned by the caller
  • Matrix decodables own copies of their input matrices
