Detailed Description

Matrix-backed decodables: precomputed scores as DecodableInterface.

This file is copied/modified from src/decoder/decodable-matrix.h. These classes wrap a matrix of per-frame log-likelihoods as a DecodableInterface, optionally mapping transition-ids to pdf-ids through a TransitionInformation. They are the efficient alternative to a per-call custom decodable when the score matrix is already available: every LogLikelihood() call is an O(1) matrix access.

The matrix layout matches kaldi's: row t holds the per-pdf (or per-index) log-likelihoods of frame t,

\[ L \in \mathbb{R}^{T \times P}, \qquad \mathrm{LogLikelihood}(t, i) = s \cdot L_{t,\,\pi(i)} \]

where \(\pi\) is the tid->pdf map and \(s\) the acoustic scale.

Adaptations to this port:

  • kaldi's Matrix<BaseFloat> is this repo's FloatMatrix (Eigen row-major)
  • kaldi's MatrixBase/SubMatrix overloads are simplified to FloatMatrix
  • the raw look-aside pointer trick of kaldi's non-KALDI_PARANOID build is replaced by direct Eigen coefficient access (identical semantics)

Common ownership rules:

  • The owning constructors copy/keep the matrix and delete it in the destructor; the borrowing constructors never free it
  • The decodable itself is owned by the caller (decoders only borrow it)

General usage pattern:

  1. Compute a (num_frames, num_pdfs) score matrix
  2. Wrap it in the decodable that matches your mapping/scale needs
  3. Hand the decodable to any decoder (it is a DecodableInterface)
kaldi_decoder::FloatMatrix likes(100, 11); // 100 frames x 11 pdfs
// ... fill likes ...
kaldi_decoder::DecodableMatrixScaledMapped dec(tm, likes, 0.083f);
float s = dec.LogLikelihood(0, 1); // scale * likes(0, pdf of tid 1)
