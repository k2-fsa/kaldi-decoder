Detailed Description

Utterance-level alignment and decoding helpers.

This file is copied/modified from src/decoder/decoder-wrappers.h. Where kaldi's binaries (gmm-align-compiled, gmm-latgen-faster) write tables, these functions return plain out-params:

  • AlignUtteranceWrapper: forced alignment of a known word sequence;
  • DecodeUtteranceLatticeFaster / DecodeUtteranceLatticeSimple: one utterance of decoding;
  • LatticeBestPath: the core of lattice-best-path – 1-best under lm/acoustic scaling.
