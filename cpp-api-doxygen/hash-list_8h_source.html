21/* This header provides utilities for a structure that's used in a decoder (but
22 is quite generic in nature so we implement and test it separately).
23 Basically it's a singly-linked list, but implemented in such a way that we
24 can quickly search for elements in the list. We give it a slightly richer
25 interface than just a hash and a list. The idea is that we want to separate
26 the hash part and the list part: basically, in the decoder, we want to have a
27 single hash for the current frame and the next frame, because by the time we
28 need to access the hash for the next frame we no longer need the hash for the
29 previous frame. So we have an operation that clears the hash but leaves the
30 list structure intact. We also control memory management inside this object,
31 to avoid repeated new's/deletes.
32*/
33
