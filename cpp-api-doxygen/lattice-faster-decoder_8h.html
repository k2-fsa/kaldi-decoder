Detailed Description

The standard lattice decoder (kaldi's LatticeFasterDecoder).

This file is copied/modified from src/decoder/lattice-faster-decoder.h. The decoder behind gmm-latgen-faster: beam-pruned token passing that keeps near-best alternatives as a lattice. See kaldi's doc/lattices.dox and doc/decoders.dox.

LatticeSimpleDecoder, decoder-wrappers.h, DecodableInterface.
