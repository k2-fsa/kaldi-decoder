Decode one utterance with LatticeSimpleDecoder.

Produces the outputs kaldi's gmm-latgen-simple writes (adapted from src/decoder/decoder-wrappers.cc: the table writers are replaced by out-params). As in kaldi, alignments/words come from the DECODE-TIME best path (decoder.GetBestPath), and *like_ptr gets its total cost. If lat_out is non-nullptr it receives the raw lattice exactly as kaldi writes it: acoustic costs divided by acoustic_scale (skipped when acoustic_scale == 0).

bool kaldi_decoder::LatticeBestPath ( const fst::Lattice & lat,

float acoustic_scale,

1-best of a lattice under lm/acoustic scaling.

The core of kaldi's lattice-best-path binary (lattice-best-path): scale the lattice by (lm_scale, acoustic_scale) via fst::ScaleLattice(fst::LatticeScale(...)) and return the 1-best (ShortestPath) as alignment/word sequences, [ ␇rg\min_P \; \lambda_{\mathrm{lm}} G(P)

  • \lambda_{\mathrm{ac}} A(P) ] where $G $ is the graph cost (Value1) and $A $ the acoustic cost (Value2). *like_ptr gets the negated total cost of the best path.

Note on ties: kaldi's binary uses CompactLatticeShortestPath, which on exact total-cost ties keeps the first predecessor in topological order; this implementation uses fst::ShortestPath, which breaks equal sums by smaller graph cost (Value1). Costs are identical; the 1-best may differ on exact ties only.

Typical scoring use (kaldi's local/score.sh over lmwt/wip grids) is to call this on the lattice returned by DecodeUtteranceLattice* with acoustic_scale=1.0 (that lattice already has acoustic costs divided by the decode acoustic scale) and lm_scale sweeping the lm weights.

Parameters
[in]latInput lattice.
[in]lm_scaleWeight of the graph cost (kaldi –lm-scale).
[in]acoustic_scaleWeight of the acoustic cost.
[out]alignmentsBest path (transition-ids); empty on failure.
[out]wordsBest path (word ids); empty on failure.
[out]like_ptrNegated total cost (optional).
Returns
True on success; false if the lattice has no complete path (outputs are cleared) – like kaldi's binary, this does not abort a scoring sweep on one bad lattice.

◆ ModifyGraphForCarefulAlignment()

void kaldi_decoder::ModifyGraphForCarefulAlignment ( fst::VectorFst< fst::StdArc > * fst)

This function modifies the decoding graph for what we call "careful alignment".

The problem we are trying to solve is that if the decoding eats up the words in the graph too fast, it can get stuck at the end, and produce what looks like a valid alignment even though there was really a failure. So what we want to do is to introduce, after the final-states of the graph, a "blind alley" with no final-probs reachable, where the decoding can go to get lost. Our basic idea is to append the decoding-graph to itself using the fst Concat operation; but in order that there should be final-probs at the end of the first but not the second FST, we modify the right-hand argument to the Concat operation so that it has none of the original final-probs, and add a "pre-initial" state that is final.
