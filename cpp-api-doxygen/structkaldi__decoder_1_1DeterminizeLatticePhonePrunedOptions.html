Detailed Description

Options for phone-aware lattice determinization (kaldi's DeterminizeLatticePhonePrunedOptions).

This is kaldi's src/lat/determinize-lattice-pruned.h options struct used by DeterminizeLatticePhonePrunedWrapper in kaldi.

Used by:
Callers that determinize the raw lattices from LatticeFasterDecoderTpl::GetRawLattice() phone-aware (kaldi's compact-lattice output path).
