Detailed Description

Options for lattice determinization (kaldi's DeterminizeLatticePrunedOptions).

This is kaldi's src/lat/determinize-lattice-pruned.h options struct (the determinization algorithms themselves come from kaldifst).

Used by:
Callers that plug kaldifst's determinization into the raw lattices produced by LatticeFasterDecoderTpl::GetRawLattice().
