Detailed Description

template<typename Token>
struct kaldi_decoder::decoder::ForwardLink< Token >

A forward link in the lattice (kaldi's decoder::ForwardLink).

Links connect tokens of adjacent frames; near-best predecessors within the lattice beam are kept so the raw lattice can be produced at the end.
