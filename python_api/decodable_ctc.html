DecodableCtc

A matrix-backed decodable for CTC-style scores, matching the spirit of kaldi's DecodableMatrixScaled but without any transition-model mapping (see kaldi-decoder/csrc/decodable-ctc.h). You hand in a (num_frames, num_classes) matrix of log-probabilities; the class copies it.

Indices are one-based: log_likelihood(t, 1) is column 0. This is for compatibility with openfst labels.

Usage

import numpy as np
import kaldi_decoder as kd

# 2 frames x 2 classes of log-probs
log_probs = np.array([[-0.1, -5.0],
                      [-5.0, -0.1]], dtype=np.float32)

decodable = kd.DecodableCtc(log_probs, offset=0)
decodable.num_frames_ready()          # 2
decodable.num_indices()               # 2
decodable.log_likelihood(0, 1)        # -0.1  (frame 0, class 0)
decodable.log_likelihood(1, 2)        # -0.1  (frame 1, class 1)

# `offset` lets row 0 of the matrix correspond to frame `offset` of the
# utterance (chunked streaming).
decodable = kd.DecodableCtc(log_probs, offset=3)   # frames 3..4

Equivalent in kaldi

kaldi has no CTC decodable; the closest is feeding precomputed per-frame scores to a decodable-matrix class:

# kaldi equivalent: per-frame scores in a matrix, consumed by
# DecodableMatrixScaled (src/decoder/decodable-matrix.h)

API reference

class kaldi_decoder.DecodableCtc(self: kaldi_decoder.lib._kaldi_decoder.DecodableCtc, log_probs: Annotated[numpy.typing.ArrayLike, numpy.float32, '[m, n]'], offset: SupportsInt = 0)

Matrix-backed decodable for CTC-style scores.

A (num_frames, num_classes) matrix of log-probabilities becomes a decodable; the matrix is copied. Indices are one-based: log_likelihood(t, 1) reads column 0.

Parameters:

  • log_probs -- Per-frame log-probs, numpy.ndarray (float32).

  • offset -- Frame index of row 0 -- use a non-zero offset when the matrix is a later chunk of a streaming utterance.

Construct from a log-probability matrix (copied).

Parameters:

  • log_probs -- (num_frames, num_classes) float32 array.

  • offset -- Frame index of row 0 (default 0).
