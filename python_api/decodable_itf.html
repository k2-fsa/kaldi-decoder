DecodableInterface

The scoring interface every decoder consumes, matching kaldi's DecodableInterface (see kaldi-decoder/csrc/decodable-itf.h). Implement it in Python to plug any acoustic model into the decoders; the pybind11 trampoline keeps virtual dispatch on the Python side.

A decodable answers one question: how likely is transition-id ``index`` at frame ``frame``? Indices are one-based (openfst convention).

Usage

import kaldi_decoder as kd

class MyDecodable(kd.DecodableInterface):
    def num_frames_ready(self) -> int:
        return 100

    def is_last_frame(self, frame: int) -> bool:
        return frame == self.num_frames_ready() - 1

    def num_indices(self) -> int:
        return 30          # number of transition-ids (1-based)

    def log_likelihood(self, frame: int, index: int) -> float:
        # higher is better; return the acoustic log-likelihood of
        # transition-id `index` at `frame`.
        return my_scores[frame, index - 1]

decodable = MyDecodable()
decoder = kd.FasterDecoder(graph, kd.FasterDecoderOptions(beam=16.0))
decoder.init_decoding()
decoder.advance_decoding(decodable)

Lifetime rule: decoders hold a reference to the decodable (and to the graph) without owning it. The decoder keeps the graph alive automatically; the decodable is only needed during the decode calls.

Equivalent in kaldi

Any kaldi decoder binary takes scores from a GMM/NN model internally; the DecodableInterface is exactly the seam kaldi uses between the acoustic model and the decoder:

# kaldi computes these scores internally via DecodableAmDiagGmmScaled etc.
gmm-latgen-faster --max-active=7000 --beam=13.0 --lattice-beam=6.0 \
    --acoustic-scale=0.083 final.mdl HCLG.fst \
    "scp:split.1/feats.scp" "ark:|gzip -c > lat.1.gz"

API reference

class kaldi_decoder.DecodableInterface(self: kaldi_decoder.lib._kaldi_decoder.DecodableInterface)

Scoring interface every decoder consumes.

This is kaldi's DecodableInterface. It answers one question: how likely is transition-id ``index`` at frame ``frame``? Implement it in Python to plug any acoustic model into the decoders (a pybind11 trampoline keeps virtual dispatch on the Python side).

Indices are one-based (openfst convention, 0 is epsilon).

Lifetime: decoders borrow the decodable without owning it -- keep the Python object alive for the whole decode.

See also

DecodableMatrixScaledMapped For the fast matrix-backed implementation.

Construct a decodable; implement the four methods below.

is_last_frame(self: kaldi_decoder.lib._kaldi_decoder.DecodableInterface, frame: SupportsInt) → bool

Whether frame is the last frame with scores available.

For streaming decodables this is only true once the input is finished.

log_likelihood(self: kaldi_decoder.lib._kaldi_decoder.DecodableInterface, frame: SupportsInt, index: SupportsInt) → float

Acoustic log-likelihood of transition-id index at frame frame (higher is better).

Parameters:

  • frame -- Frame index, 0-based, frame < num_frames_ready().

  • index -- Transition-id, 1-based, index <= num_indices().

Returns:

The log-likelihood.

num_frames_ready(self: kaldi_decoder.lib._kaldi_decoder.DecodableInterface) → int

Number of frames with scores available; may grow over time.

num_indices(self: kaldi_decoder.lib._kaldi_decoder.DecodableInterface) → int

Number of valid indices (transition-ids); indices are 1-based.
