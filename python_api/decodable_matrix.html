Decodable matrix classes

Precomputed log-likelihood matrices wrapped as decodables, matching kaldi's decoder/decodable-matrix.h (see kaldi-decoder/csrc/decodable-matrix.h). Use these whenever the full score matrix is already available -- they are the efficient alternative to a per-call Python decodable: all log_likelihood calls stay in C++.

Four classes, same names as kaldi:

  • DecodableMatrixScaledMapped -- acoustic scale + tid->pdf mapping (GMM/NN scores are per-pdf; decoders ask per transition-id).

  • DecodableMatrixMapped -- same mapping, no scale, with a frame offset.

  • DecodableMatrixMappedOffset -- incrementally fed chunks (multi-threaded decoding).

  • DecodableMatrixScaled -- no mapping; columns are the indices directly.

Usage

import numpy as np
import kaldi_decoder as kd

# tm: a kd.TransitionInformation (e.g. wrapping your transition model)
likes = np.random.randn(100, 11).astype(np.float32)  # 100 frames x 11 pdfs

decodable = kd.DecodableMatrixScaledMapped(tm, likes, scale=0.083)
decodable.num_frames_ready()       # 100
decodable.num_indices()            # tm.num_transition_ids()
decodable.log_likelihood(0, 1)     # scale * likes[0, tid_to_pdf[1]]

# chunked input (frames arrive in pieces):
dec = kd.DecodableMatrixMappedOffset(tm)
dec.accept_loglikes(chunk1, frames_to_discard=0)
dec.accept_loglikes(chunk2, frames_to_discard=1)  # drop 1 old frame
dec.input_is_finished()
dec.first_available_frame()        # frames below this are gone

Lifetime: the constructors copy the numpy matrix and own the copy. The numpy array may be deleted immediately afterwards (see the regression test test_lifetime_after_numpy_gone).

Equivalent in kaldi

# kaldi: the same classes consume a Matrix<BaseFloat> of per-pdf likes,
# e.g. produced by a neural net and written with matrix-write.
nnet3-compute ... | matrix-copy ark:- ark:likes.ark

API reference

class kaldi_decoder.DecodableMatrixScaledMapped(self: kaldi_decoder.lib._kaldi_decoder.DecodableMatrixScaledMapped, tm: kaldi_decoder.TransitionInformation, likes: Annotated[numpy.typing.ArrayLike, numpy.float32, '[m, n]'], scale: SupportsFloat)

Matrix-backed decodable with acoustic scale and tid->pdf mapping.

kaldi's DecodableMatrixScaledMapped. The matrix must have tm.num_pdfs() columns; row t holds the per-pdf log-likelihoods of frame t. The score of transition-id tid at frame t is scale * likes(t, tid_to_pdf[tid]).

The numpy matrix is copied and owned by the decodable; it may be deleted right after construction.

Parameters:

  • tm -- Transition model providing the tid->pdf map.

  • likes -- (num_frames, num_pdfs) float32 array.

  • scale -- Acoustic scale (kaldi --acoustic-scale).

class kaldi_decoder.DecodableMatrixMapped(self: kaldi_decoder.lib._kaldi_decoder.DecodableMatrixMapped, tm: kaldi_decoder.TransitionInformation, likes: Annotated[numpy.typing.ArrayLike, numpy.float32, '[m, n]'], frame_offset: SupportsInt = 0)

Matrix-backed decodable with a frame offset (chunked scores).

kaldi's DecodableMatrixMapped: like DecodableMatrixScaledMapped but without an acoustic scale and with a frame offset -- row 0 of likes is frame frame_offset of the utterance. Useful when scores arrive in chunks.

The numpy matrix is copied and owned by the decodable.

  • likes -- (num_frames, num_pdfs) float32 array.

  • frame_offset -- Frame index of row 0.

class kaldi_decoder.DecodableMatrixMappedOffset(self: kaldi_decoder.lib._kaldi_decoder.DecodableMatrixMappedOffset, tm: kaldi_decoder.TransitionInformation)

Incrementally-fed matrix decodable for streaming/threads.

kaldi's DecodableMatrixMappedOffset: call accept_loglikes() whenever a new chunk of per-pdf scores is available; old frames can be discarded to bound memory. Querying a frame below first_available_frame() is an error.

tm -- Transition model providing the tid->pdf map.

class kaldi_decoder.DecodableMatrixScaled(self: kaldi_decoder.lib._kaldi_decoder.DecodableMatrixScaled, likes: Annotated[numpy.typing.ArrayLike, numpy.float32, '[m, n]'], scale: SupportsFloat)

Plain matrix-backed decodable with an acoustic scale (no map).

kaldi's DecodableMatrixScaled: columns ARE the indices (one-based): the score of index at frame t is scale * likes(t, index - 1). Use when the caller already has per-index scores (e.g. CTC-like graphs).

The numpy matrix is copied and owned by the decodable.

Parameters:

  • scale -- Acoustic scale.
