Decoder wrappers

Utterance-level alignment and decoding helpers, adapted from kaldi's decoder-wrappers.h (see kaldi-decoder/csrc/decoder-wrappers.h). Where kaldi's binaries write tables, these return plain Python lists:

  • align_utterance_wrapper -- forced alignment of a known word sequence (the engine of kaldi's gmm-align-compiled);

  • decode_utterance_lattice_faster / decode_utterance_lattice_simple -- one-utterance decoding (the engine of gmm-latgen-*);

  • lattice_best_path -- kaldi's lattice-best-path core: 1-best of a lattice with lm-scale / acoustic-scale / word-ins-penalty scoring.

Usage

import kaldifst
import kaldi_decoder as kd

# ---- forced alignment (== gmm-align-compiled) ----
graph = kaldifst.StdVectorFst.read("train_graph.fst")   # keep alive
decodable = MyDecodable()
(num_done, num_error, num_retried, tot_like, frame_count,
 alignment, words) = kd.align_utterance_wrapper(
     config=kd.AlignConfig(beam=200.0, retry_beam=0.0, careful=False),
     utt="utt1", acoustic_scale=0.1, fst=graph, decodable=decodable,
     num_done=0, num_error=0, num_retried=0, tot_like=0.0, frame_count=0)

# ---- decoding (== gmm-latgen-faster) ----
decoder = kd.LatticeFasterDecoder(graph, kd.LatticeFasterDecoderConfig())
ok, alignment, words, like, lat = kd.decode_utterance_lattice_faster(
    decoder=decoder, decodable=decodable, trans_model=tm,
    utt="utt1", allow_partial=False, acoustic_scale=0.1)

# ---- scoring the lattice (== lattice-best-path) ----
# `lat` is written like kaldi writes it: acoustic costs / acoustic_scale.
# Sweep lm weights / word insertion penalties like local/score.sh does:
for lmwt in (0.5, 0.75, 1.0):
    ok, ali, words, like = kd.lattice_best_path(
        lat, lm_scale=lmwt, acoustic_scale=1.0)

Lifetime: the graph is borrowed (keep it alive); the returned lat is an owned copy.

Equivalent in kaldi

# kaldi: forced alignment
gmm-align-compiled --transition-scale=1.0 --acoustic-scale=0.1 \
    --self-loop-scale=0.1 --beam=200 --retry-beam=0 final.mdl \
    "ark:graphs.fsts" "scp:feats.scp" "ark:|gzip -c > ali.gz"

# kaldi: decoding
gmm-latgen-faster --acoustic-scale=0.1 final.mdl HCLG.fst \
    "scp:feats.scp" "ark:|gzip -c > lat.gz"

# kaldi: lattice scoring (kaldi's local/score.sh loop)
lattice-best-path --lm-scale=0.75 --word-ins-penalty=0 \
    "ark:gunzip -c lat.gz|" ark:tra.ark

kaldi_decoder.align_utterance_wrapper(config: kaldi_decoder.AlignConfig, utt: str, acoustic_scale: SupportsFloat, fst: fst::VectorFst<fst::StdArc>, decodable: kaldi_decoder.DecodableInterface, num_done: SupportsInt, num_error: SupportsInt, num_retried: SupportsInt, tot_like: SupportsFloat, frame_count: SupportsInt) → tuple[int, int, int, float, int, list[int], list[int]]

Forced-align one utterance (kaldi's gmm-align-compiled core).

Returns (num_done, num_error, num_retried, tot_like, frame_count, alignment, words). The five counters are INPUTS that get incremented (they mirror kaldi's accumulating table writers) -- thread them through a loop over utterances.

Parameters:

  • config -- Alignment beams (AlignConfig).

  • utt -- Utterance id (for log messages).

  • acoustic_scale -- Acoustic scale used in the decode.

  • fst -- Per-utterance training graph; mutated when config.careful is set (pass a copy to reuse it).

  • decodable -- Scores (DecodableInterface).

Returns:

The 7-tuple above; alignment is transition-ids, words the word ids.

Decode one utterance (kaldi's gmm-latgen-faster output block).

Returns (ok, alignment, words, like, lat). alignment/words are the DECODE-TIME best path (what kaldi writes to its words/alignment tables); lat is the raw lattice exactly as kaldi writes lat.gz (acoustic costs divided by acoustic_scale).

Parameters:

  • decodable -- Scores (DecodableInterface).

  • trans_model -- Transition information.

  • utt -- Utterance id (for log messages).

  • allow_partial -- Output partial results if no final state was reached.

  • acoustic_scale -- Acoustic scale used in the decode.

Returns:

See above.

kaldi_decoder.lattice_best_path(lat: fst::VectorFst<fst::ArcTpl<fst::LatticeWeightTpl<float>, int, int>, fst: :VectorState<fst::ArcTpl<fst::LatticeWeightTpl<float>, int, int>, std: :allocator<fst::ArcTpl<fst::LatticeWeightTpl<float>, int, int> > > >, lm_scale: SupportsFloat = 1.0, acoustic_scale: SupportsFloat = 1.0) → tuple[bool, list[int], list[int], float]

1-best of a lattice under lm/acoustic scaling (kaldi's lattice-best-path).

Minimizes lm_scale * graph_cost + acoustic_scale * acoustic_cost. On the lattices returned by decode_utterance_lattice_faster() (acoustic costs already divided by the decode acoustic scale), use acoustic_scale=1.0 and sweep lm_scale for lmwt scoring.

Parameters:

  • lat -- Input lattice (kaldifst.Lattice).

  • lm_scale -- Weight of the graph cost (kaldi --lm-scale).

  • acoustic_scale -- Weight of the acoustic cost (kaldi --acoustic-scale).

Returns:

(ok, alignment, words, like); ok is False when the lattice has no complete path (outputs empty).
