FasterDecoder

kaldi's FasterDecoder (see kaldi-decoder/csrc/faster-decoder.h): a beam-pruned Viterbi decoder for FSTs without self-loops (e.g. transducers built with add-self-loops-style graphs need a lattice decoder instead). It is the fastest of the three simple decoders.

Usage

import kaldifst
import kaldi_decoder as kd

graph = kaldifst.StdVectorFst.read("HCLG.fst")   # keep it alive!
decodable = MyDecodable()

opts = kd.FasterDecoderOptions(beam=16.0, max_active=100, min_active=20,
                               beam_delta=0.5, hash_ratio=2.0)
decoder = kd.FasterDecoder(graph, opts)
decoder.init_decoding()
decoder.advance_decoding(decodable)      # or advance one frame at a time:
decoder.advance_decoding(decodable, max_num_frames=1)
decoder.num_frames_decoded()
decoder.reached_final()
ok, best = decoder.get_best_path()

# change settings mid-stream
decoder.set_options(kd.FasterDecoderOptions(beam=8.0))

Equivalent in kaldi

# kaldi's faster-decoder backs e.g. gmm-decode-faster
gmm-decode-faster --beam=16.0 --max-active=100 final.mdl graph.fst \
    "scp:feats.scp" ark:tra.ark

class kaldi_decoder.FasterDecoder(*args, **kwargs)

Beam-pruned Viterbi decoder (kaldi's FasterDecoder).

For FSTs without self-loops and without the need for a lattice; the fastest decoder. Use LatticeFasterDecoder for general HMM graphs.

Lifetime: the decoder holds a reference to the graph (py::keep_alive); the graph is released automatically when the decoder is destroyed. The decodable is only needed during the decode calls.
