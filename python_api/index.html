Python API

The Python bindings live in the kaldi_decoder module (the extension is kaldi_decoder/lib/_kaldi_decoder). Building graphs needs the kaldifst package; kaldi-decoder itself does not construct FSTs.

Each page below has a usage example, the equivalent kaldi commands, a kaldi-flag mapping table, and the full API reference.
