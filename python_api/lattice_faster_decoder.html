LatticeFasterDecoder

kaldi's LatticeFasterDecoder (see kaldi-decoder/csrc/lattice-faster-decoder.h): the standard lattice decoder used by gmm-latgen-faster. Beam-pruned token-passing that keeps alternative paths in a lattice, with separate beam (paths) and lattice_beam (lattice detail) controls. This is the right default for decoding with self-loops (HMM graphs).

Usage

import kaldifst
import kaldi_decoder as kd

graph = kaldifst.StdVectorFst.read("HCLG.fst")   # keep it alive!
decodable = MyDecodable()

cfg = kd.LatticeFasterDecoderConfig(beam=13.0, lattice_beam=6.0,
                                    max_active=7000)
decoder = kd.LatticeFasterDecoder(graph, cfg)

ok = decoder.decode(decodable)             # one-shot ...
# ... or incremental:
decoder.init_decoding()
decoder.advance_decoding(decodable)        # all available frames
decoder.finalize_decoding()

decoder.reached_final()
ok, best = decoder.get_best_path()         # 1-best traceback
ok, raw = decoder.get_raw_lattice()        # full lattice

Equivalent in kaldi

# this decoder is the engine of kaldi's gmm-latgen-faster
gmm-latgen-faster --max-active=7000 --beam=13.0 --lattice-beam=6.0 \
    --acoustic-scale=0.083 final.mdl HCLG.fst \
    "scp:feats.scp" "ark:|gzip -c > lat.1.gz"

class kaldi_decoder.LatticeFasterDecoder(self: kaldi_decoder.lib._kaldi_decoder.LatticeFasterDecoder, fst: fst::Fst<fst::StdArc>, config: kaldi_decoder.lib._kaldi_decoder.LatticeFasterDecoderConfig)

The standard lattice decoder (kaldi's LatticeFasterDecoder), the engine of gmm-latgen-faster.

Beam-pruned token passing that keeps near-best alternative paths (within lattice_beam) as a lattice. See How the decoders work for the algorithm and Decoding an utterance for a walkthrough.

Lifetime: the decoder holds a reference to the graph (py::keep_alive); the graph is released automatically when the decoder is destroyed. The decodable is only needed during the decode calls.
