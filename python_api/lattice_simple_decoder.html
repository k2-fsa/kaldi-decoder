LatticeSimpleDecoder

kaldi's LatticeSimpleDecoder (see kaldi-decoder/csrc/lattice-simple-decoder.h): like SimpleDecoder but keeps a lattice (alternative paths with their acoustic/graph costs) instead of just the 1-best. Use it when you need get_raw_lattice() on a small graph.

Usage

import kaldifst
import kaldi_decoder as kd

graph = kaldifst.StdVectorFst.read("HCLG.fst")   # keep it alive!
decodable = MyDecodable()

cfg = kd.LatticeSimpleDecoderConfig(beam=16.0, lattice_beam=10.0)
decoder = kd.LatticeSimpleDecoder(graph, cfg)
ok = decoder.decode(decodable)
decoder.reached_final()
ok, best = decoder.get_best_path()      # 1-best as a kaldifst Lattice
ok, raw = decoder.get_raw_lattice()     # alternatives within lattice_beam

# or drive it incrementally
decoder.init_decoding()
decoder.finalize_decoding()

Equivalent in kaldi

# kaldi's lattice-simple-decoder backs gmm-latgen-simple
gmm-latgen-simple --beam=16.0 --lattice-beam=10.0 --acoustic-scale=0.083 \
    final.mdl HCLG.fst "scp:feats.scp" "ark:|gzip -c > lat.gz"

class kaldi_decoder.LatticeSimpleDecoder(*args, **kwargs)

Lattice-generating Viterbi decoder (kaldi's LatticeSimpleDecoder).

Like SimpleDecoder but keeps alternative paths within lattice_beam as a lattice. See get_raw_lattice().

Lifetime: the decoder holds a reference to the graph (py::keep_alive); the graph is released automatically when the decoder is destroyed. The decodable is only needed during the decode calls.
