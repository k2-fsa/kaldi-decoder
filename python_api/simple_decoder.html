SimpleDecoder

A Viterbi decoder over a static FST, matching kaldi's SimpleDecoder (see kaldi-decoder/csrc/simple-decoder.h). It keeps one token per FST state (no beam pruning of states beyond the beam value) and is best for small graphs or as a reference decoder.

Usage

import kaldifst
import kaldi_decoder as kd

graph = kaldifst.StdVectorFst.read("HCLG.fst")   # keep it alive!
decodable = MyDecodable()                        # see DecodableInterface

decoder = kd.SimpleDecoder(graph, beam=16.0)
ok = decoder.decode(decodable)          # True if tokens survive to the end
decoder.reached_final()                 # True if a final state was reached
ok, best = decoder.get_best_path()      # best path as a kaldifst Lattice
decoder.final_relative_cost()           # inf => no final state reached

Lifetime: the decoder holds a reference to graph (released with the decoder); temporaries are safe.

Equivalent in kaldi

# kaldi's simple-decoder is used by gmm-decode-simple etc.
gmm-decode-simple --beam=16.0 final.mdl graph.fst \
    "scp:feats.scp" ark:tra.ark

class kaldi_decoder.SimpleDecoder(*args, **kwargs)

Simple Viterbi decoder (kaldi's SimpleDecoder).

Keeps one token per FST state; good for small graphs or as a reference.

Lifetime: the decoder holds a reference to the graph (py::keep_alive); the graph is released automatically when the decoder is destroyed. The decodable is only needed during the decode calls.
