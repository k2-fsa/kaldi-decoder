TransitionInformation

The transition-model interface the decode wrappers use for tid->pdf mapping and phone queries, matching kaldi's TransitionInformation (see kaldi-decoder/csrc/transition-information.h). Implement it in Python to use Decoder wrappers with any transition model, or use kaldi_hmm_gmm.TransitionModel from the kaldi-hmm-gmm package, which implements the same interface in C++.

Usage

import kaldi_decoder as kd

class MyTm(kd.TransitionInformation):
    def transition_ids_equivalent(self, a: int, b: int) -> bool:
        return self.transition_id_to_pdf_array()[a] == \
               self.transition_id_to_pdf_array()[b]

    def transition_id_is_start_of_phone(self, tid: int) -> bool:
        return tid in self.phone_starts

    def transition_id_to_phone(self, tid: int) -> int:
        return self.tid2phone[tid]

    def is_final(self, tid: int) -> bool:
        return tid in self.final_tids

    def is_self_loop(self, tid: int) -> bool:
        return tid in self.self_loop_tids

    def transition_id_to_pdf_array(self) -> list:
        # index 0 is unused; transition-ids are one-based
        return [-1, 0, 1, 1, 2, 3]

    def num_pdfs(self) -> int:
        return 4

Note: transition_id_to_pdf_array must return the whole map every call (it is cached by the trampoline; the cached reference is what decodables keep).

Equivalent in kaldi

kaldi implements this interface in TransitionModel (src/hmm/transition-model.h), which is built from a tree + topology:

# kaldi: TransitionModel is read from a .mdl file
gmm-info exp/mono0a/final.mdl

API reference

class kaldi_decoder.TransitionInformation(self: kaldi_decoder.lib._kaldi_decoder.TransitionInformation)

Transition-model interface used by the decode wrappers.

kaldi's TransitionInformation: provides the tid->pdf map and per-transition-id queries. Implement it in Python to use align_utterance_wrapper() / decode_utterance_lattice_faster() with any transition model; kaldi_hmm_gmm.TransitionModel implements the same interface in C++.

Note: transition_id_to_pdf_array() must return the whole map on every call (the trampoline caches it; that cached reference is what decodables keep).

Implement the pure virtual methods in a subclass.
